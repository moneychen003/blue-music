蓝亦云音乐

一个免费开源、纯净无广告的跨平台音乐播放器。简洁的蓝色界面，桌面歌词、收藏、批量下载，一应俱全。

支持 Windows · macOS · Linux · Web

核心特性

为听歌而生的纯净体验

跨平台

一套体验覆盖 Windows、macOS、Linux 与浏览器，数据本地保存，纯净无负担。

透明桌面歌词

悬浮于桌面的逐行歌词，可拖动、可锁定鼠标穿透，不挡操作。

我喜欢 & 收藏

一键收藏喜欢的歌曲、专辑与歌单,「我喜欢的音乐」随身携带。

批量下载

多选歌曲批量下载，按歌手归类、自动去重，离线随时听。

蓝色主题

清爽的蓝色界面与图标，深色模式护眼，专注听歌不分心。

扩展生态

通过扩展接入多种在线音乐源，搜索、歌单、排行榜随心听。
